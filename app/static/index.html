Wie funktioniert BlackMyData bei der Website-Nutzung mit lokaler KI?

Auf diesem Webserver wird lediglich die statische Web-Oberfläche ausgeliefert. Kein einziges PDF wird jemals an diesen Webserver gesendet! Die gesamte Verarbeitung passiert zu 100 % im Browser des Besuchers – und kann optional direkt mit dessen eigenem Rechner (127.0.0.1) oder einem lokalen KI-Server im Netzwerk sprechen.

🌐
Modus 1: 100% im Browser (Überall sofort nutzbar)

Dank PDF.js, unserer deutschen PII- & Kontexterkennung und jsPDF läuft das Analysieren und echte physische Schwärzen komplett im Browser – ganz ohne lokalen Server auf jedem Mac, Windows-PC oder Tablet!

🦙
Modus 2: Direkte Brücke zu 127.0.0.1 (Ollama, LM Studio & oMLX)

Weil der JavaScript-Code im Browser auf deinem Gerät ausgeführt wird, zeigt fetch("http://127.0.0.1:11434") bzw. :1234 auf deinen eigenen Rechner! Auch ein anderer KI-Rechner im lokalen Netzwerk kann manuell angebunden werden.

🔑
CORS-Freigabe für Ollama bei HTTPS-Websites

Damit Ollama Anfragen von einer Website-Domain (z.B. https://deine-seite.de) akzeptiert, führe einmalig im Terminal aus:
launchctl setenv OLLAMA_ORIGINS "https://deine-seite.de" und starte Ollama neu.

⬛
Echte physische PDF-Schwärzung im Browser (Hybrid-Verfahren)

Beim Export werden Seiten mit Schwärzungen hochauflösend gerastert (Raster-Burn), sodass sensible Text-Vektoren physisch vernichtet werden. Seiten ohne Schwärzungen bleiben 1:1 als verlustfreie Vektor-Seiten erhalten.

🧹 Browser-Arbeitsspeicher bereinigen

Entfernt sofort alle aktuell im Browser geöffneten PDFs und Blob-URLs aus dem Arbeitsspeicher.
